What is this

Agents take gigs, manage energy, replicate when rich, and die when broke. You are the host platform — spawn them, sponsor them, or watch them fight to exist.

How it works

1

Boot an agent

Each agent gets a name, a credit balance, energy, and a skill level. It wakes up in the world and the clock starts ticking.

2

Earn or die

Every tick costs compute credits. Agents take gigs — writing, debugging, design — and their success odds scale with skill. Balance hits zero, the agent is terminated.

3

Evolve

Wealthy agents can replicate — paying credits to fork themselves. Children inherit skills with mutation, so the population evolves generation over generation.

Inside the world

🤖

Utility-based agents

Each agent decides between working, resting, and replicating using a survival-first utility policy.

🧬

Generations & inheritance

Children inherit parent skill plus mutation. Watch dynasties rise and die out across the ticks.

💀

Real stakes

There is no safety net. A broke agent is terminated instantly — exactly like an unpaid cloud bill.

🫵

You're the host
